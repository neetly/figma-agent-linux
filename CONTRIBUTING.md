# Contributing

Contributions are welcome. Keep changes focused, explain their purpose, and
validate them as appropriate before submitting.

## LLM Policy

You may use large language models (LLMs) and coding agents to help with your
contribution, subject to the following requirements:

- **Understand your changes.** You must review the contribution and have a basic
  understanding of what it changes and why. You should be able to explain the
  changes and respond to review feedback. You remain responsible for the work
  you submit, including any LLM-generated content.
- **Credit LLM assistance.** Every commit containing LLM-assisted work must
  include a `Co-authored-by:` trailer identifying the model or tool used. For
  example:

  ```text
  Co-authored-by: Codex <noreply@openai.com>
  ```

- **Keep a human involved.** Fully automated agent contributions are prohibited.
  A human contributor must direct the work, review the result, and take
  responsibility for the submission. Do not submit unreviewed agent output or
  run agents that independently create and submit contributions without human
  oversight.
